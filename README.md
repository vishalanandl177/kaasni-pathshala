# Kaasni Pathshala — policy pages

The privacy policy, terms of use and about page for the Android app
**Kaasni Pathshala**, published at
<https://vishalanandl177.github.io/kaasni-pathshala/privacy.html>.

Google Play requires a privacy policy at a public URL for any app whose
audience includes children, and it re-checks that the link still works after
launch. These four files are the whole site: no build step, no framework.

They are generated from the documents in the app's own repository by
`tool/build_site.py`, which is where any change should be made. Editing the
HTML here by hand would be undone the next time the site is rebuilt.
